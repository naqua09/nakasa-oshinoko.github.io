## 🛍️ 【推しの子】× 有馬温泉 お買い物ラリー達成度ログ

有馬温泉の各対象店舗で商品購入や日帰り入浴を利用すると、オリジナルカードがもらえるお買い物ラリーの巡回達成度を記録・シェアできるWebアプリケーションです。

- **お買い物ラリーURL**: `rally.html`
- **ログイン不要**: ブラウザの `localStorage` に自動保存
- **X（旧Twitter）シェア**: 達成店舗数・オリジナルカード獲得数をポスト可能

### 対象店舗・対象商品一覧（全6店舗）

1. **三ツ森**：クリーム炭酸せんべい
2. **湯泉神社**：1,000円以上お買い上げ
3. **佃煮元祖 川上商店本店**：ちりめん山椒&てまり昆布(生姜)
4. **hetekara**：あぶらとり紙&無添加石鹸
5. **湯屋の宿 康貴**：日帰り入浴利用
6. **上大坊**：日帰り入浴利用
   - **※重要**: 土日祝日に日帰り入浴を利用する場合は、受付で**「推しの子コラボで日帰り入浴したい」**と伝える必要があります。
